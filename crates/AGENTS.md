# Crates

- `axioval-ir` — source-neutral data and normalized package contracts.
- `axioval-engine` — compiler, trusted registry, services, runtime.
- `axioval-rules` — reusable capability policy and algorithms.
- `axioval-openbim` — OpenBIM semantic adapter.
- `axioval-axiolid` — independent Axiolid geometry adapter.
- `axioval-icdd` — ICDD project assembly adapter.
- `axioval` — feature-gated facade.
- `axioval-cli` — command-line frontend.
