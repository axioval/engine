# `axioval-host-ifc-axiolid`

The IFC→Axiolid geometry bridge as a library: IFC bodies meshed with
`ifc-geometry` and registered as the Axiolid geometry services of an IFC
`EvidenceSession`. Hosts take it through the facade's `ifc-geometry`
feature; `axioval-cli` (`check --geometry`, `compare`, `draft`, the template
benchmark) is its first consumer.

- It lives in the host layer (`crates/hosts/`) because it is host
  composition: `axioval-ifc` must not know Axiolid and `axioval-axiolid`
  must not know IFC. This crate is the only one the architecture gate
  (`HOST_CRATES`, `joined_sides` in `scripts/architecture.py`) lets depend
  on both sides; never move any of it into either adapter, and never give
  it a sink (BCF, HTML, spreadsheets) or any command-line concern.
- Its public API is what a host needs and nothing more: `attach`,
  `unattached`, `service_types`,
  `Options` (with `Frame`), `ModelBytes`, `GeometryReport`, `KeptMesh`,
  `ModelData`, the model-data integrity codes, and the derived-source
  vocabulary (`Matching`, `MatchedBy`, `DerivedMatch`, `Unmatched`,
  `DEFAULT_TOLERANCE_METRES`). Everything else is
  private; a host must never need a second reading of the IFC model to use
  what `attach` registered. `Options` and `GeometryReport` are
  `non_exhaustive`, so fields are additive. Document every public item.
- `Options::reuse` (on by default, `with_reuse`) is handed to the
  free-space service; off, it keeps nothing for a later request, only for
  the determinism gate (#441). It never changes an answer.
- `Options::timings` prints `timing: <seconds> s geometry: <phase>` on
  stderr (`src/timings.rs`), the CLI's `--timings` format; it never changes
  the result.
- `GeometryReport::meshes` (with `Options::keep_meshes`) holds each meshed
  object's triangles in model coordinates (`KeptMesh`, moved back from any
  local frame, finite and indexed), for display; the bridge never colours
  them.
- Each model's bytes are parsed with the IFC adapter's `read_ifc_xml`
  (ifcXML, `is_ifc_xml`) or `read_ifc_step`, never a codec directly, so
  geometry sees the model the session proved.
- Federation: every source is meshed into one set only where it shares the
  first source's frame (`unaligned`, through
  `axioval_rules::compare_coordinate_systems(..).shares_frame()` with the
  default tolerances); every physical object of another source is
  unmeasured with the reason, and a source whose coordinate system cannot
  be read is never assumed aligned. With `Options::declared_shared_frame`
  (#382, the CLI's `--declare-shared-frame`) a source is measured in the
  first source's frame where only missing or ambiguous statements leave it
  open (`alignment`, `only_unstated`: no world-frame or map-conversion
  difference, the only unknown a world frame stated by one or neither,
  a map conversion on one side only, or `CoordinateSystemError::Ambiguous`
  on either side) and named in `GeometryReport::declared_frame_sources`;
  a difference beyond the tolerance, a map offset that cannot be compared,
  an unreadable or unsupported coordinate system or no coordinate-system
  service stay unmeasured as without it. `local_frame` shifts every parsed
  model by the one origin regardless, so declared sources share it. Never
  re-align meshes by a map conversion here. Derived sources (#390,
  `src/derived.rs`, `Options::with_derived_from`, the CLI's
  `--derived-from`): after every service is registered, each object of a
  derived source is matched to the original's by `GlobalId` and class
  (`Matching::ById`), and with `Matching::ByIdOrGeometry` one without such
  a counterpart by its body alone, only when exactly one object of each
  side matches (a grid over box corners, never all pairs; originals some
  copy claims by id are never candidates). Bodies are compared through
  the registered `ProximityServiceHandle` in the shared world frame
  (`Fingerprint`: box corners within tolerance plus both deviations, mesh
  area within `2π (a + b + c)` times that, certified volume intervals
  within tolerance times area) as a pre-filter only, then confirmed by the
  surfaces' certified Hausdorff distance within tolerance:
  `measure_surface_distance` where the service certifies it, else
  `axiolid_measure::hausdorff_distance` between the two meshes widened by
  both deviations (`tessellated`); never by representation, triangle lists
  or identity, and never by the fingerprint alone (a moved opening keeps
  box, area and volume). Only a
  pair proven one body is declared (`EvidenceSession::with_superseded`);
  every other derived object stays evaluated, counted by `Unmatched`
  cause. Never supersede on an open interval, a missing volume or a
  refusal, and never match a
  reduced copy inside its original (a wall's core): it is not the same
  body, so only a host declaring it (`SupersessionKind::Declared`) may
  supersede it; never resolve a
  chain of derived sources (`derived::validate` refuses it). Unit tests
  pin the fingerprint; `tests/check.rs` `a_copy_a_derived_model…`,
  `a_derived_model_without_its_originals_ids…` and
  `a_copy_stated_by_another_representation…`, `a_copy_whose_opening_moved…`
  and `a_tessellated_copy_is_confirmed…` pin it end to end. Each object's model is looked up by its source, spatial
  trees are built per source, and every service is bound to all snapshots.
  Never key anything on a bare local id: two files share `#10`.
- Meshing only what the rules ask (#410): `Options::with_only` meshes
  the objects named and what measuring them as among all the others needs
  (`wanted`: every product sharing a decomposition with one through
  products that may have a body, `bodied`, never through spatial elements;
  the openings of such a whole, `IfcRelVoidsElement` edges and
  `ifc_geometry::openings_of`; the elements an opening among them voids),
  and leaves every other body out (`AxiolidGeometry::with_left_out`,
  `GeometryReport::not_meshed`), its watch armed once every service is
  registered and read by `GeometryReport::reached_left_out`. Every service
  is still registered. Each object meshed must end in the state a full
  attach gives it: when a new step makes an object's state depend on
  another object, add that object to `wanted`. Ignored with a derived
  source. `unattached` is the report of a host attaching nothing;
  `service_types` lists every handle type `attach` may register, for a
  host's watch (`EvidenceSession::watching`): keep it complete.
- Below, `tests/check.rs` is `crates/apps/cli/tests/check.rs`, which runs
  the bridge end to end through `check --geometry`; the unit tests live
  here beside the code they pin. `geometry.*` names the CLI result's
  record of `GeometryReport`.
- Run `cargo test -p axioval-host-ifc-axiolid` for the unit tests and
  `cargo test -p axioval-cli --test check with_geometry` end to end; any
  change that can move an outcome also runs the public parity test
  (`AXIOVAL_PARITY_MODELS=… cargo test -p axioval-cli --test parity --
  --ignored`).

## The bridge's rules

- `src/lib.rs` is the bridge's one pass over the objects (`attach`). Every object must end in exactly one state: exact mesh, tessellated mesh, no body, or unmeasured. Never declare a physical product bodiless because meshing failed; that makes it vanish from contact and free-space checks. A physical product with no `Body` of its own is measured through its parts (`Composer`): the session's `IfcRelAggregates` edges (`RelationshipSelectionServiceHandle::edges`, one listing, never a query per object), inner wholes first, then `AxiolidGeometry::compose` after `with_boundaries`. Any unmeasured part leaves the whole unmeasured naming it (`no body representation of its own, and …`); no parts stays unmeasured as `no shape representation` when `Representation` is `$` (model data: also one `shape.no-representation` integrity warning per object, `GeometryReport::model_data`, never measured as empty) or as `no body representation; it has <identifiers>` when it has representations none of which is a body; an unreadable edge listing leaves every such whole unmeasured with the reason. `geometry.composed` is additive. A product left unmeasured by its own meshing (a compiler refusal), or a whole left unmeasured, gets a bound for the space service: a whole whose parts could not be composed the union of its parts' boxes, each kept apart (`AxiolidGeometry::parts_bounds`: measured parts' boxes and unmeasured parts' boxes, none if any part is unbounded; never their hull, which refuses a space between two parts), otherwise the box its `Box` representation states (`stated_box`: every `IfcBoundingBox` corner placed by the context's world coordinate system above the placement chain, never the corner and extents as world axes), otherwise, for a product with openings to subtract, its gross body's mesh extent grown by its certified deviation (`gross_bound`, #301: the net body lies inside it), otherwise its `Body` items bounded one by one, the body within the union of their boxes (`src/outer_bound.rs`, #358, `Reach`: boxes kept apart up to `MAX_BOXES`, then their hull; an extrusion's sweep is always one box from end to end, never its two ends apart; a compiled item's mesh box grown by its deviation; a difference, intersection or half-space clip by its first operand only; a union by both; a polygon mesh, triangle mesh or planar straight-edged B-rep by its authored vertices; a refused linear extrusion by its profile's box (`profile_rings` grown by `profile_deviation`, certified only) swept along it; instances and mapped items carry the corners; an item whose lowering is refused read through its IFC boolean or mapped item; anything else gives none, never a guess). Anything unreadable gives no box, never a guessed one; an unaligned source's products get none, and a whole measured through its parts is measured, never bounded. Such a product also gets an enclosure for free-floor searches where one is certified (#401, `with_unmeasured_enclosure`): `enclosure` compiles the subjects of its net body's differences (`difference_subjects`, outermost first, at most `MOST_SUBJECTS`) and takes the first the compiler measures with a certified fit (the gross body before its openings, else an authored difference's subject), placed by the transform above it with its deviation scaled by the placement's Frobenius norm, with the net body's certified elevations; a part a whole's opening cannot be cut from is enclosed in its body before it. Never enclose a body that is no difference, and never in a subject whose fit is uncertified. `tests/check.rs` pins a layered wall, a stair, a roof with a bodiless slab and the whole/part pairs a clash must not report. A whole's own openings (#223, `WholeOpenings`): bodies are registered only after them. Each opening of a whole is compared with each measured part beneath it (at any depth) by `cuts`: two exact bodies cell by cell of the opening's mesh (`OpeningCell`: a convex connected piece, one prism per cap triangle of an extrusion, else the cells its own face planes split its box into (`arrangement`, #316: each in or out by the winding number of its centre, signed by the piece's orientation; none when it crosses itself or exceeds `MAX_CELL_PLANES`/`MAX_CELLS`), else a convex cell holding the piece, which only ever decides clear and is also tried when an arrangement cell stays open), the part cutting a cell when its surface reaches into the cell's core shrunk by `TOUCHING_DEPTH` (10 µm) or the core lies inside it by winding number (`cell_cut`); what that leaves open and every tessellated pair by the certified shared volume (`shared_volume_cut`: beyond a layer `TOUCHING_DEPTH` thick over the opening's faces inside the part's box (`contact_area`) or the opening inside the part cuts, within `TOUCHING_VOLUME` or apart is clear, between is undecided; never widen clear to the layer, which a volume cannot show reaches nowhere deeper). Never decide it by a penetration witness, which reads deep on a face an opening shares with a hole already cut, and never by the kernel's shared volume alone: on cut Brep layers it is refused or spans `[0, the part's volume]` (corpus m01). It is subtracted only from the parts it cuts (`mesh_less`: the part's net body less the opening's `Body`, in world coordinates; a several-solid operand is refused by the graph, never cut in part), and a part it cannot be decided for, lies around, or cannot be cut from (nothing left of it is a named refusal too, never #310's voided body, which is about its own openings) is unmeasured naming the opening and the whole, which then fails closed naming the part. An opening without a body to compare leaves the whole unmeasured naming it (`refused`); a `Reference`-only one under `TakeAsApplied` is taken as applied to the whole (`reference_only` mirrors ifc-geometry's reading; never widen it). Every cut body and each whole holding it is named with `with_whole_openings` (`;whole-openings:`), and `geometry.whole_openings` (additive) lists each decided opening with the parts it was subtracted from. `tests/check.rs` pins an uncut layered wall with a pipe through its door, the same wall already cut (`Body` and `Reference` openings) unchanged, a turned wall with a rebated Brep window flush with its cut layers unchanged (#316), and the refusals; the unit tests `a_wholes_opening_cuts_a_part_only_where_it_reaches_into_its_material`, `a_wholes_opening_of_several_pieces_or_any_profile_is_read_by_its_shape`, `a_wholes_stepped_opening_is_read_cell_by_cell_of_its_planes` and `a_wholes_opening_cuts_by_volume_only_beyond_the_cut_tests_depth` pin the decision. The planarity check may only grow by structures proven planar; anything unrecognised stays tessellated. A section profile is polygonal only with every fillet and edge radius absent or zero (its straight and sloped edges are exact); any radius is chorded.
- Space-boundary coverage registers every `IfcSpace` and every `IfcRelSpaceBoundary` naming one. A boundary's `ConnectionGeometry` is read through `ifc-spatial`'s `SpaceBoundary::connection_geometry` and lowered through `ifc-geometry`'s `lower_connection_surface` (surfaces, face surfaces, face-based surface models) in the frame `product_representation_frame` gives the space's `Body` representation (openbimrs/ifc#164), the same frame lowering places the body in; never rebuild that frame or place the mesh afterwards. A curve-bounded plane takes the frame on its basis plane only (openbimrs/ifc#163). A space without a body representation falls back to its placement; its coverage is refused anyway. Anything not lowered (no geometry, not a surface, refused by the lowering or compiler) is an unmeasured boundary, never skipped. `axiolid-mesh-compile` is a direct dependency only to require 0.3.5 (curve-bounded planes, axiolid/kernel#192; section profiles meshed from their exact contour, axiolid/kernel#193; voids tangent to a host face, axiolid/kernel#194).
- Every compiler refusal goes through `compilation_refused` and leaves the object unmeasured. `BudgetExceeded` (since mesh-compile 0.3.8 and construct 0.3.10 a turn needing more than 4096 steps to meet the chord tolerance, axiolid/kernel#231) gets a reason naming the tolerance and the resource; never retry it with a coarser tolerance or accept a coarser mesh under the declared deviation. `tests/check.rs` pins it with a ring 5 km round. Every mesh goes through `compile`: a planar one (a bounded half-space with a polyline boundary included, `SolidOperation::BoundedHalfSpace` or `BoundedHalfSpaceAlongZ`, axiolid/kernel#321) is exact and compiled with plain `compile_mesh`. Since mesh-compile 0.3.27 a bounded half-space's slab is sized from the subject it cuts, so a small boundary over a tall solid cuts through it (axiolid/kernel#322, #325, engine#412; unit test `a_small_bounded_clip_over_a_tall_wall_is_cut_through_and_measured`, `tests/check.rs` `…clipped_within_a_composite_boundary_is_measured_like_its_twin`); never refuse such a clip here again. Since ifc-geometry 0.28 every `IfcPolygonalBoundedHalfSpace` lowers to `BoundedHalfSpaceAlongZ` (openbimrs/ifc#515), so a prism oblique to its plane, a non-convex boundary and one with an arc are compiled and measured (#404, `tests/check.rs` `…clipped_by_an_oblique_bounded_half_space_is_measured`); the kernel refuses by name only a `Position` Z in the clip's plane and the clip as a union's operand, a first operand or a root. the compiler may snap a boolean's operands onto each other (mesh-compile 0.3.16, axiolid/kernel#276; since 0.3.18 rounding residues only, falling back to the unsnapped operands when a snapped boolean is refused or pinches, axiolid/kernel#291, #356), but only the deviation report says by how much, and asking it for every planar boolean tripled m14's meshing (95 s to 310 s, #306), so such snaps stay undeclared; where a report is taken (planar with warped faces, `planar_width`; curved, its bound) a `deviation::SNAPPED_OPERANDS` move above `ON_SURFACE` is declared, a smaller one is rounding, and so is a `deviation::COINCIDENT_OPERANDS` one (operand faces the exact boolean read as one surface within tolerance, mesh-compile 0.3.27, axiolid/kernel#324), which a curved report's bound already holds; a curved wall less an opening or niche flush with its curved faces is therefore measured (#403; unit test `a_curved_wall_with_a_flush_opening_is_measured_within_a_certified_bound`, `tests/check.rs` `…curved_wall_with_a_flush_niche_is_measured`), and so is one whose openings abut each other or reach a few micrometres past its ends, which the exact boolean classifies near a face boundary at a finer tolerance and exactly since mesh-compile 0.3.28 (#417, axiolid/kernel#332; unit test `a_curved_wall_with_abutting_openings_is_measured_within_a_certified_bound`, `tests/check.rs` `…curved_wall_with_abutting_openings_is_measured`), and the enclosure test for a refused difference uses a tapered niche, which the exact boolean still refuses; a curved one goes through `compile_mesh_with_deviation` (mesh-compile 0.3.10, axiolid/kernel#232, #235) and is declared with the report's certified bound as returned (never the 1 mm budget by assumption; a curved boolean's is measured against the exact compiler's result and reads close to the budget), and one with no bound (`Unbounded`: booleans the exact compiler refuses, tapered extrusions, sectioned spines) is refused through `uncertified` and left unmeasured, for bodies, opening voids and space-boundary surfaces alike. A disk swept round an unfilleted polyline corner is mitred and proven within the budget again (mesh-compile 0.3.12, construct 0.3.13, axiolid/kernel#245), so it is measured; a closed polyline and a fillet radius equal to the disk radius are still refused by the compiler by name (#248) and left unmeasured; `tests/check.rs` pins those, and both a roof-clipped wall with a round window and a beam with a hole tangent to its flange (both certified; the latter since mesh-compile 0.3.13, axiolid/kernel#243). Warped authored faces (axiolid/kernel#254, #257, #261): since mesh-compile 0.3.14 the compiler reports every `PolygonMesh` face and every B-rep face without a surface warped beyond the tolerance as `Certified` with the width of the slab its corners span about its fit plane (details `"non-planar authored face"`, `"non-planar face without a surface"`, `WARPED_FACES`), scaled by placements; it holds every reading of the face (a lifted-corner quad's two triangulations, a saddle's `2 h`). `compile` declares the body within that reported bound (`warped_width`): a planar graph with such faces outside booleans (`authored_leaves`) is compiled with a report for it, a curved one's report includes it. Never compute a warp here. Each such face under a boolean is compiled alone with a report, and a warped one leaves the body unmeasured: the compiler bounds no boolean of a polygon mesh or B-rep (the exact compiler refuses both). A graph beyond `NODE_BUDGET` is refused. Unit tests pin the lifted corner and the saddle against the gap between their triangulations, placement scaling and the boolean refusal; `tests/check.rs` a faceted wall with a corner lifted 5 cm. Faces are triangulated by the certified clipper (#260): rings bounding no region are refused by name (unmeasured); a face ring that crosses or runs back along itself is model data (`self_intersecting_face`, one `shape.self-intersecting-face` integrity warning per object, #298), while a keyhole (a hole joined to the outer boundary by a seam) is not: since construct 0.3.16 it is measured on surface paths and refused by name in an extruded profile (axiolid/kernel#270), and the `-0.0` corners that found no ear order as `0.0` (#269), both pinned by `tests/check.rs` walls `#69` and `#79` (#299); a measured product whose mesh is no closed two-manifold and whose `Body` items' faces, as authored, leave edges bounding one face only (`src/authored_faces.rs`: face sets, faceted B-reps, shell- and face-based surface models through mapped items, corners by exact coordinates, item by item) is model data too (one `shape.open-surface` integrity warning per object with the count, #311); a face set repeating its corners per face is not, since the adapter shares equal corners (#308); rings touching inside a neighbouring face's edge are welded into it since mesh-compile 0.3.15 (axiolid/kernel#265; unit test `a_vertex_on_another_rings_edge_…`), which also reports a declared solid whose mesh does not close as `MeshClosure::OpenSolid`: services read closure from `audit_mesh`, never from the compiler's label, and a boolean refuses such an operand by name (a keyhole B-rep face whose seam is a triangle edge, axiolid/kernel#283). No engine code refuses an extrusion before the kernel is asked (#317): the kernel refuses an extrusion within tolerance of its profile plane by name (`extrusion direction in the profile plane`, construct and mesh-compile alike since 0.3.17/0.3.16, axiolid/kernel#281), builds an oblique extrusion of arcs and circles with exact elliptical-cylinder walls (#280) and refuses an oblique ellipse by name; its exact boolean cuts their walls since mesh-compile 0.3.19 (axiolid/kernel#287), so a slab less an oblique round opening, upward or downward, and a clipped oblique rounded member are certified and measured (`tests/check.rs` `…oblique_extrusions…`). An extrusion against the profile normal is certified since construct 0.3.16 (axiolid/kernel#275, #301; `tests/check.rs` `…cut_down_against_their_profile_normal…`). A disk swept along an `IfcGradientCurve` is certified (#252); `tests/check.rs` measures one.
- Openings as voids (#383): every `IfcOpeningElement` stays bodiless (`NO_BODY`), and the void the bridge meshes for it anyway (its `Body`, or its `Reference` solid when some host took it as applied) is registered after the wholes are composed (`with_voids`: `with_void`, `with_tessellated_void` by its certified deviation, `with_unmeasured_void` with the reason, `GeometryReport::voids` counting the measured ones), so no service iterating bodies sees it. The proximity handle is registered with `with_voids(AxiolidProximityService::measuring_voids)`; never register voids as meshes or make the material view measure them. `tests/check.rs` `…distance_to_an_opening…`, `…contained_in_an_openings_void`, `…openings_extent_is_its_voids` and `…an_opening_never_clashes` pin it.
- A host whose net body compiles to no triangles while its gross body (`NetLowering::gross`, re-lowered in a fresh session, `gross_has_triangles`) compiles to some is unmeasured as `voided_body_reason` (its openings remove its whole body), model data with one `shape.voided-body` integrity warning per object (`VOIDED_BODY`, #310); never measure it as empty, and keep `NO_TRIANGLES` for a body empty before any opening.
- A product whose own geometry `ifc-geometry` refuses as `GeometryError::Degenerate` (`#<id> (<TYPE>) is geometrically invalid: …`, `invalid_geometry`) is model data with one `shape.invalid-geometry` integrity warning per object (`INVALID_GEOMETRY`, #357); an opening that cannot be subtracted is not. A whole whose compose fails while every part is measured, bodiless or unmeasured for model data (`Composer::model_data_part`, inner wholes through the same map) is reported with the code of the part its reason names (`model_data_notes`, #357). `model_data_code` is the one classifier; keep `scripts/not_evaluated_inventory.py` matching it. `tests/check.rs` `…unmeasured_obstacles_bounded_apart…` pins both and the bounds.
- Hosts are meshed through `lower_product_net_with` with the source's `Parsed::net` (`net_options`): `ReferenceOnlyOpenings::TakeAsApplied` only for a snapshot schema of `IFC4` or `IFC4X3`, whose `IfcOpeningElement` definition states that a `Reference` representation is not subtracted (engine#218, openbimrs/ifc#351); every other release refuses. Never decide it here from geometry or names: `ifc-geometry` takes an opening as applied only when every representation is `Reference`, and an opening with none or with another stays refused. Each taken opening is named on the host (`AxiolidGeometry::with_applied_openings`, so evidence carries `;applied-openings:`) and in the result's additive `geometry.openings_taken_as_applied` with its reason (`applied_reason`; an `AppliedReason` this bridge does not know leaves the host unmeasured). Its void is its `Reference` solid (`reference_void`), only for openings some host took as applied. `tests/check.rs` pins a host measured with a `Reference` opening, one voided by a `Body` opening and one left unmeasured by an opening without representation. Since `ifc-geometry` 0.13 (openbimrs/ifc#388) the openings are subtracted in the host's frame and the net root (like `gross`, each `Subtraction::body` and `result`) is an `Instance` with the host's world transform above them; `compile`, `planar`, `authored_leaves` and `exact_boundary` walk through it, so never match the root as a boolean or read a `Subtraction::body` as the placed solid. `tests/check.rs` pins a wall with flush openings under a georeferenced, turned site (engine#303).
- IFC4X3 stations, `IfcOffsetCurveByDistances` and sectioned solids and surfaces lower through `ifc-geometry` (≥ 0.9, openbimrs/ifc#307); a sectioned solid stays unmeasured until the mesh compiler certifies a bound between stations, and stations it refuses by name (an `IfcParameterValue`; other offset bases lower since `ifc-geometry` 0.20, openbimrs/ifc#414, `with_geometry_stations_on_an_offset_basis_lower`, and single stations on offsets of gradient, spiral, B-spline or ellipse bases since 0.22, openbimrs/ifc#423, and sectioned runs along those since 0.23, openbimrs/ifc#429, `with_geometry_a_run_along_an_offset_ellipse_lowers`, and `IfcOffsetCurveByDistances` along them as curves since 0.24, openbimrs/ifc#433, with sections along them since 0.25, openbimrs/ifc#443, their lengths certified since mesh-compile 0.3.25, axiolid/kernel#307, and an offset of an offset refused by name, axiolid/kernel#289) stay unmeasured with that reason. Since mesh-compile 0.3.28 the compiler bounds runs whose frames it reads by quadrature (along an ellipse or B-spline and offsets beside a line, circle, ellipse or B-spline, axiolid/kernel#316), so `with_geometry_stations_on_an_offset_basis_lower` and `with_geometry_a_run_along_an_offset_ellipse_lowers` are measured, and `with_geometry_a_run_along_offsets_by_distances_of_an_ellipse_reaches_the_mesh_compiler` stays unmeasured only for the cell beside the mitre at its offset's corner; since `ifc-geometry` 0.18 stations on composite and trimmed bases and on joints lower (openbimrs/ifc#346, `tests/check.rs` `with_geometry_stations_on_a_composite_basis_lower`). A product on an `IfcLinearPlacement` is placed by deriving its frame from the basis curve (engine#224, `ifc-geometry` ≥ 0.10, openbimrs/ifc#353, #355): every lowering goes through `session()` (`LoweringSession::with_curve_evaluator(&EVALUATOR)`, the `axiolid-evaluate` reference evaluator) and every placement read through `world_transform` or `product_representation_frame_with_evaluator`; never call `LoweringSession::new`, `product_world_transform` or `product_representation_frame` for a product here (only `Linear`'s own check reads alignments' local placements plainly). A cached `CartesianPosition` is verified (`CACHED_POSITIONS` = `CachedPositionPolicy::Verify`, #354); never switch to `Trust`, which would place a product by a stale cache. `Linear` (per source, `Parsed::linear`) refuses every linear placement whose derivation would ignore a stated frame (openbimrs/ifc#357: a `PlacementRelTo` off the identity, a basis curve held by a product placed off the identity, or held by no representation while an alignment is), and `mesh`, `reference_void`, `stated_box`, `space_frame` and the levels check it first (a host also for its openings), so such a product is unmeasured with the reason, never misplaced and never bounded; drop it only once `ifc-geometry` composes both. `tests/check.rs` pins an `IfcParameterValue` refused by name (#347), a length placed, a disagreeing cache refused and an agreeing one placed, and the #357 refusals; the unit test `a_lateral_offset_places_a_product_left_of_its_curve_and_upright` pins #355.
- `src/local_frame.rs` (#372) measures a model whose outermost placement lies beyond `EXACT_REACH` in plan about a local origin: every placement relative to nothing has the first model's chosen root location subtracted (file units, new point and axis placement, the root re-pointed) right after `parse`, before anything composes; heights never move. All models of a session share one origin or none (any linear or grid placement, alignment, rotated context world coordinate system, body without placement or unreadable root leaves every model in model coordinates). `attach` hands the origins to `AxiolidGeometry::with_local_origins` and `EvidenceSession::with_local_origins` (object frames and leaves in the same frame), and `kept_mesh` here, like the CLI's `bounds.rs` and `zones.rs`, moves positions back; a host comparing two sessions' geometry (the CLI's `compare`) passes `with_model_frame(true)`. Never compose a world transform and subtract afterwards: the rounding at the large magnitude is then already in it. Never let a position leave the engine (message, evidence, value, BCF) in the local frame.
- `src/alignment.rs` is the `AlignmentService` (engine#252), registered with `--geometry`. Each `IfcAlignment` is read as an elevated centreline: its `Axis` curve lowered through `session()`, else `ifc_alignment::gradient_curve3`; a banked curve by its base; its placement and context must be the identity (`rigid` refuses any other, naming openbimrs/ifc#357; allow rigid frames only once `ifc-geometry` composes alignment placements). Reference points are placement origins through `world_transform`, and a placement `Linear` refuses is refused with that reason. The foot is certified, never searched for by sampling alone: bisection of `g(d) = (P - c) . c'` pruned only by the Lipschitz bound from `curve_derivative_bounds3`, split at `continuity_breaks3`; values widened over the winning bracket by the same bounds, with `slack` for the evaluator. Overlapping candidates are ambiguous, an end nearest is off the range; never clamp or pick. Parameters follow their laws (`curvature`, `gradient`, `cant`, each refusing a law it cannot bound by name); add a law only with a bound proven over a stretch, never by sampling. Unit tests pin straight, arc, hairpin ambiguity, off-range and the gradient-curve fixture; `tests/check.rs` judges cubes by `station` and `offset` along an alignment. `src/alignment/profile.rs` answers `measure_alignment_profile`: the parameter's laws as leaves along plan distance, each value and rate proven from its law (polynomial derivatives by interval Horner, a vertical arc's `(1 + g^2)^(3/2) / R` monotone in `|g|`, the cant shapes' unimodal slopes peaking at mid-segment), split at station equations and every `step`; authored seam values stay exact, computed ones are widened; a law without a rate bound is refused by name. The vertical curvature (`profile::vertical_curvature`, also what `measure_alignment_parameter` answers) reads the same leaves: polynomial elevations by interval arithmetic on `z'`, `z''`, `z'''`, a vertical circle as its constant `1 / R`; never a second reading of the laws. Unit tests read a layouts-only IFC4X3 alignment (no `Axis`); `tests/check.rs` judges `max_along`, `min_along` and `rate_along` on it. `src/alignment/elements.rs` answers `measure_alignment_elements` from the layouts' segments as stated (`ifc_alignment::AlignmentView::layout_segments`, `VerticalLayout::resolve`), read apart from the centreline, without the closing zero-length segment: a zero radius is a straight end, a parabola's radius is read only where `L / (g2 - g1)` agrees with it, a vertical clothoid's ends are unread; never default a curvature. Its unit tests pin a crest of R = 5000 m measured at its midpoint and a clothoid's parameter; `tests/check.rs` judges both end to end.
- `src/alignment/section.rs` cuts sections and sweeps clearance envelopes (engine#253) over the bridge's `AxiolidGeometry` along the same centrelines, so an alignment refused for positions (off the identity, openbimrs/ifc#357) is refused here too; never compose its frame here. The section frame is the plan frame (horizontal left normal, `+Z` up). Only a closed mesh is cut (each directed edge matched by its reverse; a body measured through its parts is refused for a section), with one vertex classification and one canonical cut point per edge, so segments close exactly; the radius is the certified deviation plus `frame_error`. A sweep step is cleared only by the 3D test of triangles clipped to the slab around its mid section against the envelope grown by `D = h (B1 + |u|max B2 / speed)` plus the deviation and the frame's error, or by the winding number when no triangle is that near; a near body is proven inside by a section witness or the step halved (`DEPTH`, `SWEEP_BUDGET`), and what stays undecided is `Possible`, never `Clear`. Unmeasured or open bodies refuse the sweep. Unit tests pin a box's area and thickness, straight and curved sweeps, thin plates crossing between samples (never clear) and the refusals; `tests/check.rs` judges `envelope_intrusions` and `station_section_area` end to end.
- `src/alignment/sight.rs` answers `measure_sight_distance` (engine#340) along the same centrelines. Targets step forward from the eye; a step is clear only when the gradient line is proven below every sight line of it (the developed profile, the target's movement bounded by `t h Δg`, pieces bounded from the law's certified gradient and halved to `PROFILE_DEPTH`, never below the evaluation's error) and `SightObstacles::near` clears the step's reach `h (B1 + |u| B2 / speed)` plus `frame_error`; a target is blocked only by a sampled gradient point above its sight line or `SightObstacles::blocking`. What is neither leaves the interval open (`NARROWEST`, `SIGHT_BUDGET`), never clear. Unit tests pin the parabolic crest's closed form and a wall inside a curve; `tests/check.rs` judges both end to end.
- Every tessellated body's height is read from the graph its mesh is compiled from (`Body::height`, `axioval_axiolid::certified_vertical_extent`, #393), with or without exact boundaries, and registered with `with_vertical_extent_bounds` right after its mesh, which ignores it unless it agrees with the mesh. Never read it from a second lowering or from the IFC entities. `tests/check.rs` `…a_curved_slab_and_a_column_ending_at_the_floor…`, `…a_duct_through_the_floor…` and `…an_uncertified_round_top…` pin it.
- With `Options::exact_boundaries` (the CLI's `--geometry` without `--no-exact-boundaries`), `attach` also builds each body's exact boundary from the lowered graph its mesh is compiled from (`axioval_axiolid::exact_boundary`), never from a second reading of the IFC entities, so placement and mirroring are the mesh's. It registers only boundaries that pass `check_exact_boundary` (with `with_exact_body`: a body less its extruded openings or clipped by half-spaces is exact where the kernel's boolean report is empty and perturbed by what it reports otherwise, several items stay in the body's frame), and only when some tessellated body has one. `GeometryReport::exact_boundaries` counts them.
- Register a geometry service only when every role it needs can be read from IFC; otherwise leave it unregistered so its rules report `missing-service`.
- `src/glazing.rs` (`BodyItems`, #205) supplies the leaf-glazing service's items door by door, read on a door's first request and cached: `ifc-geometry`'s `body_description` (mapped items resolved, each item's `item_world` and `mapped_by`), each item lowered through `session()` and compiled alone through `compile`, and whether it is glazing from the adapter's `GlazingReader` (one per source, built on first use). A described body it refuses, a linear placement `Linear` refuses, or an item that cannot be lowered or meshed refuses the door's items whole; an item compiling to no triangles is left out. It owns the parsed models after every other service is built (`Arc<BTreeMap<SourceId, Parsed>>`). `tests/check.rs` `with_geometry_a_glazing_ratio_is_judged_per_leaf` pins one glazed and one solid leaf, an unstyled pane and a stated fraction.
- `with_levels` declares every `IfcBuildingStorey` a `spans-level` level: its placement's world height up to the next storey's of the same spatial parent. A tilted or unreadable placement, or a height shared with a sibling, is an unmeasured level, never a guessed band.
